# By Projets — ma vie par projets

Une application web installable (PWA) pour **piloter toute sa vie par projets** :

**Thèmes** (domaines de vie) → **Projets** → **Sous-projets**. Chaque sous-projet a une fiche QQOQCCP, un tableau de suivi qu'on coche au quotidien, un document vivant exportable en PDF et signable, et une place dans **Ebenezer**, l'archive des projets accomplis.
