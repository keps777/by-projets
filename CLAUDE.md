# CLAUDE.md

Projet **NexG-TT** (Next Generation Travel Ticket) : PWA où le billet d'avion devient un **droit de voyage** (acheter neuf / en revente / en drop, détenir, revendre à prix encadré, transférer, nommer le voyageur à J-1, bagages en soute partagée, intentions d'achat avec fonds réservés). Deux faces : **jour** (recto · Voyager) et **nuit** (verso · Mes actifs).

- **Français** partout. Mode démo : aucun paiement réel, données fictives, compagnies fictives (Aérolys, Nordelle).
- Lire `CONTRIBUER.md` (contrat), `docs/ecrans.md` (maquette → route → phase), `docs/journal.md` (début et fin de session).
- Maquettes de référence : `design/` (lecture seule). Commande de vérification : `npm run check`.
- Ne jamais committer de secret. Un droit de voyage n'est pas un placement financier : jamais de « gain garanti ».
